**`techs` → `employees` DB migration (handled by Drizzle migration SQL — NOT in schema.ts):**
The generated migration must:
1. `CREATE TABLE employees` (per spec)
2. `INSERT INTO employees (org_id, badge, email, name, phone, rank, role, employment_type, is_active, hourly_rate, hire_date, pin_hash, session_token, token_expiry, created_at) SELECT 'APT-CA', badge, NULL, name, phone, rank, 'tech', 'hourly', is_active, hourly_rate, NULL, pin_hash, session_token, token_expiry, created_at FROM techs`
3. Push subscriptions in `techs.push_sub` (JSON blob) are NOT migrated — push subscriptions expire and must be re-registered by each tech on next login. Discard them.
4. `DROP TABLE techs`
Note: drizzle-kit may generate only the CREATE TABLE and DROP TABLE — the INSERT is a one-time data migration. If drizzle-kit does not generate the INSERT automatically, add it manually to the migration SQL file before running migrate. Flag this to Claude Code at Task 3.

**New tables — write exactly per `PHASE3_SCHEMA_SPEC.md` definitions.** Do not deviate from column names or types in the spec.

**Unique and partial-unique constraints to add via Drizzle:**
```typescript
// On properties — composite unique:
export const properties = pgTable('properties', { ... }, (t) => ({
  uniqAddressKey: unique().on(t.orgId, t.addressKey),
}));

// On employees — partial unique indexes (badge unique only where not null; email unique only where not null):
export const employees = pgTable('employees', { ... }, (t) => ({
  uniqBadge: uniqueIndex('employees_org_badge_idx').on(t.orgId, t.badge).where(sql`badge IS NOT NULL`),
  uniqEmail: uniqueIndex('employees_org_email_idx').on(t.orgId, t.email).where(sql`email IS NOT NULL`),
}));

// On push_subscriptions — composite unique:
export const pushSubscriptions = pgTable('push_subscriptions', { ... }, (t) => ({
  uniqEndpoint: unique().on(t.employeeId, t.endpoint),
}));

// On tradeDurationDefaults — composite unique:
export const tradeDurationDefaults = pgTable('trade_duration_defaults', { ... }, (t) => ({
  uniqCategory: unique().on(t.orgId, t.category),
}));
```
