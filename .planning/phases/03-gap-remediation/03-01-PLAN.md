    The root cause: field() closes over the outer `body` variable and uses regex patterns anchored on `(?:^|\n)`. In Apple Mail forwarded emails, the actual form content appears after a `---------- Forwarded message ---------` separator with `> ` prefixes on every line. The regex cannot match `> Description:` against `(?:^|\n)Description`.

    STEP 1 — Add a new inner function `fieldFromBody(names, targetBody)` that is a clone of field() but takes an explicit `targetBody` parameter instead of closing over `body`. This new function must be placed inside detectLaphamForm() alongside the existing field() function.

    The new function signature and body:
      function fieldFromBody(names, targetBody) {
        for (var i = 0; i < names.length; i++) {
          var re  = new RegExp('(?:^|\\n)' + names[i] + '\\s*:?\\s*([^\\n]+)', 'i');
          var m   = targetBody.match(re);
          if (m && m[1].trim()) return m[1].trim();
          var re2 = new RegExp('(?:^|\\n)' + names[i] + '[^\\n]*\\n\\s*([^\\n]+)', 'i');
          var m2  = targetBody.match(re2);
          if (m2 && m2[1].trim()) return m2[1].trim();
        }
        return '';
      }

    STEP 2 — After the existing field() function definition (after line 201), add forwarded-block detection and stripping:
      var forwardedBody = '';

      if (fwdIdx !== -1) {
