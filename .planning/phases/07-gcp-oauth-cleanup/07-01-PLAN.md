<objective>

used by production. "CC2.0 Dispatch" is a legacy client from the previous iteration that is
no longer referenced anywhere. Leaving it active is unnecessary attack surface.

Brandon performs all tasks in the GCP dashboard. No code changes. No AG involvement.
</objective>
