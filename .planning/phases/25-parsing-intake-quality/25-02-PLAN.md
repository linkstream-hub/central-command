<objective>
Build the Neon two-way access-info sync endpoint and the requester/tenant email comms functions. The access-sync route compares inbound WO access info against the stored `properties.accessInfo` and merges (never replaces) when new codes appear. The email functions add a requester auto-reply ("message received") and a tenant date/time coordination email, both behind the established dev write guard.

Purpose: INTAKE-04 needs the property record to gain/correct access codes from inbound WOs without losing existing codes (a wrong/missing gate code is a failed tech visit). INTAKE-06 needs every requester to get an automatic receipt. INTAKE-07's email channel coordinates date/time with the tenant; the SMS channel lands in Plan 25-03.

Output: `access-codes.ts` (pure helpers), `POST /api/intake/access-sync` route, two new `email.ts` functions, and unit tests for the pure logic.
</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-25-03 | Spoofing | /api/intake/access-sync caller | mitigate | `DASHBOARD_API_KEY` header check returns 401 before any DB access (V4 access control). |
| T-25-04 | Information Disclosure | Dev-environment email leak (real incident: 3 emails to Lapham client) | mitigate | Dev write guard (`NODE_ENV !== 'production' \|\| NEXT_PUBLIC_SANDBOX_MODE`) returns before Resend call; asserted by unit test. |
| T-25-05 | Tampering | access-info overwrite losing stored codes | mitigate | computeAccessMerge appends, never replaces; only writes when a new code is present; unit-tested. |
| T-25-06 | Denial of Service | Auto-reply loop (reply triggers reply) | mitigate | Caller gates on `senderType !== 'APT Internal'`; n8n thread-dedup (Plan 25-03) fires before this; `shouldSkipEmail` catches `auto-reply` subjects. |
| T-25-07 | Information Disclosure | RESEND_API_KEY / DASHBOARD_API_KEY in code | mitigate | Both read from `process.env`; never hardcoded; getResend lazy-init avoids build-time key requirement. |
| T-25-SC | Tampering | npm installs | accept | No new packages — uses installed resend + drizzle-orm. |
