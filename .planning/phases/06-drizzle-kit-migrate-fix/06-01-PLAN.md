<objective>
Fix `npx drizzle-kit migrate` which is broken as a standalone command. Root cause: three TTY-override hacks were added to `drizzle.config.ts` (lines 1–3) in commit a737ce0 as a workaround for drizzle-kit's stdin raw-mode errors in non-TTY environments. These hacks are in the wrong place (config file, not the drizzle-kit process) and don't fix the underlying issue.

The correct fix is a programmatic migration script using `drizzle-orm/node-postgres/migrator` with the `pg.Pool` driver (already in devDependencies). This has zero TTY dependency and works reliably in all environments.

Deliverables:
1. Remove the 3 TTY hack lines from drizzle.config.ts
2. Create `tech-pwa/scripts/migrate.ts` — programmatic migration runner
3. Add `db:migrate` and `db:generate` npm scripts to package.json
</objective>
