# Phase 18 Execution Plan: Full TechPWA Cutover (Phase C)

## Goal
Finalize the cutover of `TechPWA.gs` to Next.js API routes, transitioning the legacy Google Apps Script backend into a dead stub.

## Scope & Research Summary
- `getTechJobs` is already fully migrated to `api/field/jobs/route.ts` and wired up in the PWA.
- `getTechStatus` logic has been replaced by local storage tracking and `api/field/shift/status`.
