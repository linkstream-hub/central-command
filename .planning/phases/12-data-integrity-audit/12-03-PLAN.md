<!-- Exit code semantics (D-10, D-15) -->
EXIT_PASS = 0   # All audited tables: zero Sheets keys missing from Neon
EXIT_FAIL = 1   # jobs OR time_records have Sheets keys absent from Neon
EXIT_CONN = 2   # Connectivity failure (Sheets auth or Neon connection)

FAIL triggers: len(results["jobs"]["missing_from_neon"]) > 0
               OR len(results["time_records"]["missing_from_neon"]) > 0
NOT a FAIL trigger: job_comments count mismatch (informational only — D-07)
NOT a FAIL trigger: time_records Neon-only keys (expected from /api/field/clock-in path — D-06 + RESEARCH.md)

<!-- Terminal output format (D-11) -->
[PASS] jobs          — Sheets:   47  Neon:   47  Missing from Neon: []
[FAIL] time_records  — Sheets:  183  Neon:  185  Missing from Neon: ["TR-20260528-14"]  Neon-only (informational): 2
[INFO] job_comments  — Sheets:   92  Neon:   92  Unverified Neon rows (no sheets_id): 5

Label for PASS/FAIL: jobs, time_records use [PASS]/[FAIL]
Label for job_comments: always [INFO] (never [PASS]/[FAIL] — informational only)

<!-- JSON artifact schema (D-12) -->
{
  "run_at": "2026-06-01T14:30:00Z",         # utcnow().isoformat() + "Z"
  "window_days": 21,
  "overall": "PASS" | "FAIL",
  "tables": {
    "jobs": {
      "sheets_count": N,
      "neon_count": N,
      "missing_from_neon": [...],             # list of job_id strings
      "neon_only": [...]                      # list of job_id strings (informational)
    },
    "time_records": {
      "sheets_count": N,
      "neon_count": N,
      "missing_from_neon": [...],             # FAIL trigger if non-empty
      "neon_only": [...]                      # informational (direct clock-in path)
    },
    "job_comments": {
      "sheets_count": N,
      "neon_count": N,
      "unverified_neon": N                    # rows with sheets_id IS NULL
    }
  }
}

<!-- overall field logic -->
overall = "PASS" if (
  len(tables["jobs"]["missing_from_neon"]) == 0
  and len(tables["time_records"]["missing_from_neon"]) == 0
) else "FAIL"
job_comments does NOT affect overall.

<!-- --table flag behavior -->
--table jobs           → only run jobs audit; skip time_records and job_comments
--table time_records   → only run time_records audit; skip jobs and job_comments
--table job_comments   → only run job_comments audit; skip jobs and time_records
--table all            → run all three (default)
When only one table is run: overall = that table's pass/fail (or "INFO" for job_comments)
Missing tables omitted from the tables dict in JSON artifact.
