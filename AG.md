# AG Operational Playbook

Core stack only:

- Karpathy: think first, state assumptions, choose simple path, make surgical edits, verify outcome.
- Pocock: use focused skills/rules only when task-relevant.
- Graphify: update architecture map at meaningful milestones.
- Codegraph: navigate code by AST before editing.
- Caveman: terse technical communication.
- Agentmemory: persist durable decisions and preferences.

## Session Start

1. Read `AGENTS.md`.
2. Read `session-summary.tmp` only when continuing active work.
3. Load project docs on demand, not by default.

## Workflow

1. Define success criteria.
2. Inspect smallest relevant context.
3. Edit only required files.
4. Verify with targeted command or review.
5. Update `session-summary.tmp` when state changed.

## Forbidden By Default

- GSD commands and workflows.
- SuperClaude/SuperGravity suite activation.
- Multi-agent orchestration unless requested.
- Broad doc loading before narrow context exists.
- Feedback loops after task completion.
